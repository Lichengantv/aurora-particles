# Aurora Particles

> A stunning interactive particle universe with aurora effects, gravity wells, and real-time controls.

**Pure HTML · CSS · JavaScript — zero dependencies.**

![Aurora Particles](https://img.shields.io/badge/status-live-brightgreen) ![License](https://img.shields.io/badge/license-MIT-blue)

## Live Demo

Open `index.html` in any modern browser, or enable GitHub Pages on this repo.

## Features

- **Beautiful particle system** with soft glow and trails
- **Mouse attraction** — particles follow your cursor
- **Gravity wells** — click to place persistent attractors (max 8)
- **Double-click** to clear all wells
- **Real-time controls**:
  - Particle count (200–2500)
  - Gravity strength
  - Trail length
  - 5 color modes: Aurora Borealis, Neon Cyber, Solar Flare, Deep Ocean, Monochrome
- **Explode** button for cinematic bursts
- **Fully responsive** and touch-friendly
- High-DPI / retina ready

## How to Use

1. Move your mouse — particles are gently attracted
2. Click anywhere to drop a glowing gravity well
3. Double-click to remove all wells
4. Tweak the panel on the right to customize the experience
5. Hit **Explode** for chaos

## Tech Notes

- Canvas 2D with devicePixelRatio scaling
- Soft wrap-around edges
- Efficient trail rendering via short history arrays
- No frameworks, no build step, no external libraries
